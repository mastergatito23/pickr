## 📌 Descripción

**Pickr** es una aplicación de escritorio sencilla desarrollada en Python utilizando **CustomTkinter**. Su objetivo original era permitir a los usuarios gestionar listas de elementos (tareas, nombres, opciones) y realizar selecciones aleatorias de forma rápida e intuitiva.

---

## 🎨 Características

* Interfaz gráfica moderna basada en `customtkinter`.
* Añadido y borrado dinámico de elementos.
* Selección aleatoria con resaltado visual del elemento elegido.
* Contenedor deslizable (`CTkScrollableFrame`) para listas largas.

---

## 🛠️ Tecnologías

* **Lenguaje:** Python 3.x
* **Librería de GUI:** `customtkinter`
* **Módulo estándar:** `random`
